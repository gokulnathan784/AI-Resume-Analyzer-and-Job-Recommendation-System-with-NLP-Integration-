The project successfully developed and implemented a comprehensive AI Resume Analyzer, an interactive web application designed to automate and enhance the initial stages of the recruitment process. By integrating Natural Language Processing (NLP) techniques and Machine Learning (ML) models within a user-friendly Streamlit interface, the system effectively addresses key challenges faced by both job seekers and recruiters. The tool demonstrates robust capabilities in parsing diverse PDF resume formats, including scanned documents via its crucial OCR fallback mechanism, ensuring broad applicability.
The system accurately classifies resumes into relevant job categories using a trained Scikit-learn Logistic Regression model, facilitating efficient initial screening for recruiters. For job seekers, it provides valuable, data-driven feedback through two core features: a Job Description (JD) Matcher that quantifies resume relevance using TF-IDF and Cosine Similarity and a custom ATS Score function that evaluates resume quality against standard criteria, offering specific suggestions for improvement. The inclusion of an Admin Dashboard further enhances the system by providing insights into usage patterns and user feedback. In conclusion, the AI Resume Analyzer represents a practical and effective application of ML and NLP in the HR domain, contributing to a more efficient and potentially fairer recruitment ecosystem.
